Release pull-up 0.1.0 with YAML-only configuration and external custom commands for both npm and standalone executables. Remove the public JavaScript configuration API. JavaScript/TypeScript configs, `.pulluprc` configs, and the `package.json` `pullup` field are ignored.

Publish Linux and macOS executables for x64 and arm64 through GitHub Releases, and support `pullup --help` and `pullup --version`.
